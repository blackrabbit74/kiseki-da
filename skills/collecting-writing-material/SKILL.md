# Collecting Writing Material

## Purpose

Build a useful material bank while preserving source context and the author’s voice.

## Deliverable

Return a fragment collection with type, text or paraphrase, source location, context, intended use when known, and gaps worth exploring.

Done when: fragments remain understandable to the author and source quotations are distinguishable from paraphrases and new ideas.

Stop and report when: source content is missing for a requested quotation; leave a retrieval lead rather than guessed wording.

## Inputs

Use notes, interviews, sources, author observations, and an existing fragment collection when present.

## Decision rules

- If exact wording is unavailable, write a paraphrase rather than quotation marks.
- If the author’s fragments already exist, reread them before editing and preserve concurrent changes.
- If the material suggests competing angles, retain both without forcing an outline.
- If a fragment comes from fiction or invention, label it so it cannot later become factual evidence.

## Required procedure

1. Gather concrete material relevant to the intended subject.
2. Attach provenance and the context needed to reuse it accurately.
3. Group lightly by emerging theme and identify missing material.

## Constraints (set by: operator)

- Do not overwrite the author’s collection or force a final narrative from an exploration request. Instead, add attributable material within the requested scope.
