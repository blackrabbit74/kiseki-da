# Reducing Context Overhead

## Purpose

Identify and reduce unnecessary context while preserving task-critical constraints, decisions, and evidence pointers.

## Deliverable

Return a context inventory or compressed handoff, estimated or measured savings, retained obligations, and retrieval links for deferred detail.

Done when: the reduced context still supports the next task decision and distinguishes always-loaded content from on-demand material.

Stop and report when: the host’s loading behavior is unknown; qualify savings estimates and avoid claiming a runtime reduction. Continue independent work and identify the specific blocked action.

## Inputs

Current task, loaded components when observable, relevant files, token measurements or estimator, and required retention boundaries.

## Decision rules

- Count actual loaded content rather than every installed file.
- Deduplicate repeated facts while preserving the canonical source and exceptions.
- Move conditional detail behind a retrieval pointer; do not compress away unresolved choices or prior authorization.

## Required procedure

1. Inventory major context contributors and distinguish measured counts from estimates.
2. Remove duplication or draft a concise state summary in the requested scope.
3. Check representative next actions against retained context and report what requires later retrieval.

## Constraints (set by: operator)

Do not disable tools, rules, or safeguards merely to reduce tokens; word counts are not exact token counts. Preserve the user’s scope and existing authorization.

## Model notes

No model-specific adjustment.
