# Capturing Reusable Lessons

## Purpose

Turn observed work outcomes into scoped lessons that can improve future decisions.

## Deliverable

Return lessons with trigger, observed outcome, supporting cases, counterexamples, scope, and a proposed reuse or validation path.

Done when: each lesson is tied to evidence and clearly distinguishes tentative advice from a repeatedly demonstrated practice.

Stop and report when: evidence cannot support a proposed generalization; retain it as a hypothesis and continue other lessons. Continue independent work and identify the specific blocked action.

## Inputs

Task outcomes, failures and recoveries, user corrections, project context, and existing lessons.

## Decision rules

- Extract one decision per lesson so different causes do not share a confidence claim.
- Keep project conventions local until evidence supports broader applicability.
- Repeated observations from the same underlying event are not independent confirmations.

## Required procedure

1. Reconstruct what happened and compare intended versus actual results.
2. Identify the decision that mattered and plausible competing explanations.
3. Deduplicate lessons, record limits, and propose a realistic case that could overturn each useful rule.

## Constraints (set by: operator)

Do not enable background observation, modify policies, or install skill changes without the corresponding requested scope. Preserve the user’s scope and existing authorization.

## Model notes

No model-specific adjustment.
