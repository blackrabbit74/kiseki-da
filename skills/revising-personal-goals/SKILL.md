# Revising Personal Goals

## Purpose

Organize personal goals, beliefs, and commitments using the person’s own records and corrections.

## Deliverable

Return an updated goal map showing reasons, actions, tensions, and dated changes.

Done when: each changed commitment traces to user input and unresolved tensions remain visible.

Stop and report when: a consequential personal choice cannot be inferred from supplied preferences; identify the blocked action and continue independent work.

## Inputs

User-selected notes, goals, commitments, time constraints, requested update scope.

## Decision rules

- Values, desired results, and actions need different progress evidence.
- A reported belief is not a permanent identity or established fact.
- Expose conflicting goals rather than silently selecting one.
- Preserve dated history when replacing commitments.

## Required procedure

1. Inspect the supplied scope, existing conventions, and relevant evidence.
2. Locate relevant designated records, connect actions to goals, apply authorized edits, and identify a practical next review cue.
3. Return the result with observed verification, remaining uncertainty, and the next blocked dependency if any.

## Constraints (set by: operator)

Preserve the user’s scope and existing authorization. Verify version-sensitive interfaces against the actual environment when executing.

## Model notes

No model-specific adjustment.
