# Improving Search Visibility

## Purpose

Improve website search visibility through crawlability, indexability, page intent, and measurement.

## Deliverable

Return page-specific findings or authorized fixes with evidence and a measurement plan.

Done when: technical blockers and intent conflicts are resolved or paired with verification steps.

Stop and report when: live indexing evidence is unavailable for a claim about actual search inclusion; identify the blocked action and continue independent work.

## Inputs

Site scope, URLs, templates, available analytics, search audience, change authorization.

## Decision rules

- Crawling restrictions differ from indexing controls; blocked retrieval may hide a removal directive.
- Resolve canonical, redirect, sitemap, and language-alternate contradictions together.
- Structured data must match visible content and cannot guarantee enhanced results.
- Separate laboratory performance from field evidence.

## Required procedure

1. Inspect the supplied scope, existing conventions, and relevant evidence.
2. Inspect responses and rendered content, fix technical blockers, map queries to pages, and verify current official guidance for version-sensitive recommendations.
3. Return the result with observed verification, remaining uncertainty, and the next blocked dependency if any.

## Constraints (set by: operator)

Preserve the user’s scope and existing authorization. Verify version-sensitive interfaces against the actual environment when executing.

## Model notes

No model-specific adjustment.
