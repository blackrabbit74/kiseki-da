# Adapting Content For Channels

## Purpose

Express the same supported idea in forms suited to each audience.

## Deliverable

Return labeled channel drafts and any source or asset gaps.

Done when: each draft advances a clear claim and preserves the source meaning.

Stop and report when: missing source evidence prevents using a particular claim. Continue independent work and identify the blocked action.

## Inputs

Source material, channels, audience, voice examples, and intended action.

## Decision rules

- Adapt format and context, not the author’s identity.
- Each thread segment must advance the argument; do not pad for length.
- Verify current platform limits when final formatting depends on them.

## Required procedure

1. Extract claims, evidence, and reusable moments.
2. Draft each channel around its reading or viewing context.
3. Check unsupported additions, repetition, and voice consistency.

## Constraints (set by: operator)

Treat drafts as drafts; no fabricated personal experiences or engagement metrics. Preserve the user's scope and existing authorization.

## Model notes

No model-specific adjustment.
