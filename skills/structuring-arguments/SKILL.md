# Structuring Arguments

## Purpose

Make each part of a document earn its place in the reader’s route to the central claim.

## Deliverable

Return the requested outline or draft with a clear thesis, ordered support, necessary explanations, counterarguments, and marked evidence gaps.

Done when: each section advances the thesis and no later passage relies on an unexplained concept or unsupported factual leap.

Stop and report when: a central claim lacks necessary evidence; identify the gap and draft the supported portions.

## Inputs

Use the audience, intended takeaway, existing material, evidence, length, and author’s voice.

## Decision rules

- If the user requests a complete draft, provide it instead of requiring paragraph-by-paragraph approval.
- If two openings imply different theses, show the choice only when it changes the argument.
- If a transition needs an unintroduced idea, ground it before using it.
- If a paragraph neither advances nor qualifies the thesis, cut it or move it to supporting material.

## Required procedure

1. Establish the reader’s starting knowledge and intended takeaway.
2. Arrange evidence and explanations in the order the argument requires.
3. Draft or revise, preserving counterevidence and marking missing support.

## Constraints (set by: operator)

- Do not manufacture supporting examples, quotations, or client results. Instead, mark the evidence gap or use an explicitly fictional illustration.
